# Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| latest | ✅ |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub Issues.**

If you discover a security vulnerability, please email: **central.inbox@dustwhisperers.com**

Include the following in your report:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Any suggested fixes (optional)

You will receive a response within 48 hours. We ask that you:
- Give us reasonable time to address the issue before public disclosure
- Avoid accessing or modifying data that does not belong to you
- Act in good faith

We are committed to working with security researchers and will acknowledge your contribution once the issue is resolved.
